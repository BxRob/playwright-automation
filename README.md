# Playwright Automation

Automated UI tests for [SauceDemo](https://www.saucedemo.com/) using Playwright.

This project contains Playwright automation examples written in TypeScript and Python, using the Page Object Model (POM) design pattern.

## Technologies

- Playwright
- TypeScript
- Python
- Pytest
- Page Object Model
- Git / GitHub
